# Hardware Components

This folder contains all hardware-related components for the KLASK robotic system, including CAD files for mechanical parts and assemblies, as well as references to third-party components used in the build.

## CAD Files

The CAD files are organized in the `hardware/cad/` directory and include SolidWorks assemblies and parts for the mechanical structure of the KLASK robot. The assembly `global_assembly.SLDASM` serves as the top-level assembly that integrates all components.
