# KLASK Hardware Documentation

Welcome to the KLASK Hardware documentation! This site provides information about the hardware part of the KLASK robotic system, including its design, components, assembly instructions, and launch procedures.

If you like to build the gantry system and play a game of KLASK, the [tutorials](tutorials/00-overview.md) section will guide you through the entire process step-by-step.

For developers interested in contributing to the KLASK Hardware repo, the [development setup](tutorials/03-dev-setup.md) tutorial will help you set up your environment and show you how to debug and test your changes.
