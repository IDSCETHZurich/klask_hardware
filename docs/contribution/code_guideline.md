# Code Guideline

## Python Code

We follow the [PEP 8](https://peps.python.org/pep-0008/) style guide for Python code. To ensure consistency, we recommend using tools like [Black](https://black.readthedocs.io/en/stable/) for automatic code formatting and [Flake8](https://flake8.pycqa.org/en/latest/) for linting. This is already set up in the provided SDK container and is enforced in the CI pipeline.

## C++ Code

We adhere to the [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html). For formatting, we recommend using [clang-format](https://clang.llvm.org/docs/ClangFormat.html) with the Google style configuration. This is already set up in the provided SDK container and is enforced in the CI pipeline.
